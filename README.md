# SetoReader

Lector de mangas, manhwas y cómics para uso familiar.

Este repositorio solo publica las versiones para instalar: el APK está en **Releases** y
`version.json` le dice a la app cuándo hay una versión nueva. El código vive en otro lugar.

**Instalar:** abrir **tinyurl.com/setoreadercl** en el celular (descarga la última versión) y abrir el APK
(Android 8 o superior). Después, la app se actualiza sola.
